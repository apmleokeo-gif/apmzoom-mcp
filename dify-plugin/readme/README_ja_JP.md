# apMZoomAI · 東大門卸売

Dify のワークフローやエージェントから、ソウルの東大門卸売ファッション市場を検索できます。商品の検索、新着の確認、ビル・フロア・店舗番号での店舗探しに対応し、
すべての結果に [apMZoomAI](https://www.apmzoom.com) へのリンクが付きます（価格や卸売の注文方法はリンク先で確認できます）。

このプラグインは、apMZoomAI が公開している読み取り専用の [MCP](https://modelcontextprotocol.io) サーバー（`https://www.apmzoom.com/mcp`）を呼び出す薄いラッパーです。

ソース: https://github.com/apmleokeo-gif/apmzoom-mcp/tree/main/dify-plugin

## ツール

| ツール | 返す内容 |
| --- | --- |
| **卸売商品を検索** | 8 言語のいずれかの短いキーワードで商品を検索し、写真・カテゴリ・店舗のビル / フロア / 店舗番号・apMZoomAI のリンクを返します |
| **新着商品** | 直近 1〜168 時間にアップロードされた新着商品（ビルとカテゴリで絞り込み可） |
| **店舗を探す** | 店舗名・店舗番号、またはビルとフロアから店舗を探し、商品数とストアページのリンクを返します |
| **商品詳細** | ID で商品を 1 件取得（商品名、写真は最大 3 枚、カテゴリ、店舗の場所、リンク） |
| **ビル一覧** | 対応しているビルと、店舗数・直近 7 日の新着数・（判明している場合）営業時間と住所 |

商品名とラベルは English、中文、한국어、日本語、Tiếng Việt、ไทย、Bahasa Indonesia、Bahasa Melayu で取得できます（`lang` 入力）。すべてのツールは読み取り専用です。

**できないこと:** 価格・割引・在庫・店舗の連絡先は返さず、注文もできません。対象は現在営業中の店舗のみです。

## セットアップ

1. プラグインをインストールします。設定は不要です。
2. 5 つのツールのいずれかをワークフロー（ツールノード）またはエージェントアプリに追加します。

**認証情報 / API:** なし。アカウント、ログイン、API キーは不要です。

**接続要件:** Dify のプラグイン実行環境から `www.apmzoom.com`（443 番ポート）へ HTTPS で接続できる必要があります。apMZoomAI はネットワークアドレスごとにリクエストを制限します。

## データとプライバシー

[PRIVACY.md](../PRIVACY.md) をご覧ください。要点: プラグイン自体はデータを収集・保存しません。送信された検索語や絞り込み条件は、アカウント不要の apMZoomAI 公開 MCP サーバーで処理されます。

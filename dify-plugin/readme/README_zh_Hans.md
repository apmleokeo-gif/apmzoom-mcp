# apMZoomAI · 东大门批发

在 Dify 工作流或智能体里搜索首尔东大门批发服饰市场：查商品、看新品上架，按楼栋、楼层和档口号找档口。每条结果都带有
[apMZoomAI](https://www.apmzoom.com) 链接，买家打开链接可查看价格和批发下单详情。

本插件只是对 apMZoomAI 公开、只读的 [MCP](https://modelcontextprotocol.io) 服务（`https://www.apmzoom.com/mcp`）的一层薄封装。

源码：https://github.com/apmleokeo-gif/apmzoom-mcp/tree/main/dify-plugin

## 工具

| 工具 | 返回内容 |
| --- | --- |
| **搜索批发商品** | 用八种语言之一的简短关键词搜索商品，返回图片、品类、档口所在楼栋 / 楼层 / 档口号和 apMZoomAI 链接 |
| **新品上架** | 最近 1–168 小时内上传的最新商品，可按楼栋和品类筛选 |
| **查找档口** | 按名称或档口号、或按楼栋和楼层查找档口，返回商品数量和店铺页链接 |
| **商品详情** | 按 ID 获取单个商品：名称、最多三张图片、品类、档口位置和链接 |
| **列出楼栋** | 覆盖的市场楼栋，含档口数量、最近 7 天新品数量，以及已知的营业时间和地址 |

商品名称和标签可用 English、中文、한국어、日本語、Tiếng Việt、ไทย、Bahasa Indonesia、Bahasa Melayu 返回（`lang` 输入项）。所有工具均为只读。

**不提供的内容：** 不返回价格、折扣、库存或商家联系方式，也不能下单。只包含目前正常营业的档口。

## 使用方法

1. 安装插件，无需任何配置。
2. 把五个工具中的任意一个加入工作流（工具节点）或智能体应用。

**凭据 / API：** 无。不需要账号、登录或 API 密钥。

**网络要求：** Dify 插件运行环境需要能通过 HTTPS 访问 `www.apmzoom.com`（443 端口）。apMZoomAI 会按网络地址对请求限速。

## 数据与隐私

见 [PRIVACY.md](../PRIVACY.md)。简而言之：插件本身不收集、不存储任何数据；您发送的搜索词和筛选条件由 apMZoomAI 的公开 MCP 服务处理，该服务无需账号。

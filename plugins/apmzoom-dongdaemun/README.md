# apMZoomAI · Dongdaemun wholesale — Claude plugin

This plugin connects Claude to the apMZoomAI MCP server (`https://www.apmzoom.com/mcp`) and adds the
`dongdaemun-sourcing` skill. Together they let Claude search wholesale fashion items listed by stalls in the
Dongdaemun market in Seoul, show new arrivals, find stalls by building, floor and stall number, and link buyers
to each item or stall on apMZoomAI, in eight languages.

- The MCP server is public and read-only; no account or API key is needed.
- It never returns prices, stock levels or merchant contact details; buyers open the apMZoomAI link for those.
